# GTSRB — Распознавание дорожных знаков

## Описание проекта

Проект посвящён разработке программного прототипа системы автоматического распознавания дорожных знаков с использованием методов машинного обучения и компьютерного зрения.

Основная задача — классификация изображений дорожных знаков по одному из 43 классов датасета GTSRB (German Traffic Sign Recognition Benchmark).

Проект выполняется в учебных целях и рассматривается как упрощённая модель компонента системы помощи водителю (ADAS).

## Цель проекта

Разработать программу, которая принимает изображение дорожного знака, обрабатывает его и определяет соответствующий класс с помощью обученной модели машинного обучения.

## Используемые данные

В проекте используется датасет **GTSRB**, содержащий изображения дорожных знаков, распределённые по 43 классам.

Датасет включает изображения с различными условиями освещения, размерами и визуальными характеристиками.

Источник данных: [GTSRB — Kaggle](https://www.kaggle.com/datasets/meowmeowmeowmeowmeow/gtsrb-german-traffic-sign)

## Рассматриваемые методы

В рамках проекта рассматриваются следующие подходы:

- **HOG + SVM** — классический метод извлечения признаков и классификации изображений.
- **CNN** — сверточная нейронная сеть для автоматического извлечения визуальных признаков и классификации.
- **Transfer Learning** — перенос обучения с использованием предварительно обученной модели, например MobileNetV2.

Основным методом проекта выбрана сверточная нейронная сеть (CNN).

## Функциональные возможности

Планируемые функции программы:

1. Загрузка изображения дорожного знака.
2. Проверка и предварительная обработка изображения.
3. Классификация изображения по одному из 43 классов.
4. Отображение названия или номера распознанного класса.
5. Отображение оценки уверенности модели.
6. Предупреждение при низкой уверенности предсказания.

## Оценка качества модели

Для оценки качества классификации планируется использовать следующие метрики:

- Accuracy;
- Precision;
- Recall;
- Macro F1-score;
- Confusion Matrix;
- Время предсказания.
